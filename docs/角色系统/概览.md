# 概览

> 角色系统的玩法总览与设计思想。实现规格见《角色行动.md》，属性字段见《角色属性.md》，地图与推演规则见《大地图行军推演.md》，同盟关系见《同盟关系.md》。

---

## 术语

| 名词 | 指什么 |
| --- | --- |
| 玩家 | 坐在屏幕前的人，扮演盟主。玩家给方向、在频道里说话，不直接操纵棋子，也不参与逐格推演 |
| LLM | 大语言模型，在这里扮演具体角色。它读角色属性、可见局势与频道上下文，决定做什么、说什么，输出行动指令与发言。除玩家以外的盟主与角色都由 LLM 扮演 |
| Bot | 执行层程序，负责寻路、行军、占领、遭遇战与休整。它按指令行动，不做战略判断，也不产生台词 |

LLM 决定「做什么」，Bot 决定「怎么走」，玩家决定「往哪打」。三者不可互相代劳。

## 1. 玩家在游戏里扮演什么

玩家是盟主，不逐格操作部队。地图上每名角色都是独立的人：有自己的职位、立场和脾气，会自己判断往哪走、要不要打，也会在频道里回玩家的话。

玩家的职责是给方向——打哪、守哪、什么时候退。至于怎么打、绕哪条路、先不先要补给，由角色自己拿主意。

## 2. 设计思想

- 角色按自己的立场回话。他可以不同意，可以谈条件，也可以拒绝。只有核心团角色被写死绝对忠诚，军令一定照办
- 同一道命令，不同角色做法不同。谨慎的大臣会先问补给，勇猛的武将点兵就走
- 玩家和角色是聊天关系：玩家说一句，角色回一句，发出去就显示，不等谁「思考完」
- 角色之间的差别写在他的设定里，不写在 Bot 的代码里：职位、定位、性格决定他能做什么、倾向怎么做

## 3. 角色行动的边界

游戏里的行为分三层，玩家指挥、角色决策和 Bot 执行互不越界：

| 层 | 承担者 | 是否属于角色行动 | 职责 |
| --- | --- | --- | --- |
| 指挥层 | 盟主（玩家或 LLM） | 否 | 提出方向、目标与要求 |
| 决策层 | 角色（由 LLM 扮演） | 是 | 以角色身份理解局势、决定怎么做、决定说什么 |
| 执行层 | Bot | 是 | 寻路、行军、占领、遭遇战、休整，严格按指令行动，不做战略判断 |

**角色行动 = 角色决策 + Bot 执行。** 玩家的指挥不在里面，它只是角色做判断时的一条输入。

- 玩家在频道里说的话不算角色行动，它改变的是角色的想法
- 玩家在大地图上直接拽动核心团的 Bot 才算：这一下越过角色，直接改指令
- 所有角色都由 Bot 驱动、由自己决策，没有哪条通道可以绕开决策

## 4. 角色怎么运转

角色不等玩家每回合下令，也不每回合来请示。他隔一段时间盘算一次局势；碰上遭遇战、目标失效、刚占的地被夺这类事，会立刻反应。

一次盘算得出一份计划，照着执行一段；计划走完或中途作废，再重新判断。看上去像一直在做事，而不是一回合挪一格。

## 5. 角色是谁

职位决定他能指挥谁，定位决定他带不带兵，性格决定他冒进还是保守。字段写在《角色属性.md》。

## 6. 玩家与角色的交流

交流发生在频道里：

| 频道 | 归属 | 参与方 | 是否影响行动 |
| --- | --- | --- | --- |
| 世界 | 公共 | 所有同盟的盟主与角色 | 否，只是对话 |
| 同盟 | 每同盟一个 | 本同盟的盟主与角色 | 视角色判断 |
| 本团 | 玩家核心团 | 玩家与核心团角色 | 是，军令必然照办 |

每个同盟都有自己的盟主：玩家所在的同盟由玩家坐镇；其他同盟的盟主也是被扮演的角色，会跟自己的大臣、团长商量、下方向。别人的同盟频道玩家看不到，只能从世界频道的发言和地图上的动静猜他们在做什么。

核心团不单设盟主，它属于玩家所在的同盟。

## 7. 角色记得什么

角色有记忆：自己下过的命令、执行的结果、说过的话，还有频道里别人说过的话。新指令进来，他是在这些记忆上接着判断，不是从零开始。

## 8. 没有可用的 LLM 时

LLM 连不上或调用失败，角色改由本地规则驱动，行为流程照旧，推演不会停。差别只在说话的自然程度，界面上不提示。

## 9. 一局游戏怎么走

1. 玩家定方向：在同盟频道提出目标，或在本团频道直接下令
2. 角色接话、商议或照办，把方向变成计划
3. Bot 执行：棋子行军、占地、交战，地图跟着变
4. 玩家在世界频道与各方交涉，看其他同盟在动什么
5. 局势一变，角色重新判断，玩家再调方向
