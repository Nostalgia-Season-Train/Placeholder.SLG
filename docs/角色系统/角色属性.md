# 角色属性

> 本文定义角色的属性结构与分类术语，不涉及具体角色数值。
> 角色由「职位」与「定位」两个正交维度构成，两者互不影响。

---

## 定位

定位是能力的底子，决定攻击与魔力的倾向、上不上前线、担什么战斗职能。贬职只改职位，不改定位。

| 定位 | 攻击 | 魔力 | 前线带兵 | 职能 |
| --- | --- | --- | --- | --- |
| 武将 | 高 | 低 | 是 | 以武艺接敌作战 |
| 术武将 | 高 | 高 | 是 | 术法与武艺并用 |
| 法师 | 低 | 高 | 否 | 输出、控制、辅助一体，暂不拆分 |
| 疗愈师 | 低 | 中/高 | 否 | 恢复；增益以增伤为主 |

补充说明：

- 法师的输出、控制、辅助在同一轮内按技能区分，不单独立定位
- 疗愈师的「恢复」包含解除控制与驱散类效果
- 疗愈师的「增益」以提升伤害为主，不承担输出职能
- 法师与疗愈师不统兵，也不上前线带兵

---

## 职位

职位决定指挥权与指挥范围。有职位的人不亲自带兵，指挥的是执行层的前线单位。

| 职位 | 指挥范围 |
| --- | --- |
| 盟主 | 整个同盟，向大臣与团长下达方向 |
| 大臣 | 整个同盟 |
| 团长 | 本团团员 |

指挥链：

```
盟主 → 大臣 → 团长 → 团员（武将 / 术武将）
```

- 每个同盟的盟主不亲自带兵。玩家所在同盟的盟主是玩家本人，其余同盟的盟主由 LLM 扮演，并拥有自己的协程
- 大臣可要求团长率本团攻击指定地点，具体调度由决策层解析指令后交由 Bot 执行
- 团长只指挥本团，不跨团调度
- 无职位的角色不具备指挥权

---

## 贬职

职位可被剥夺，定位不变。

| 原职位 | 定位倾向 | 贬后归属 |
| --- | --- | --- |
| 大臣 / 团长 | 高攻击、低魔力 | 武将 |
| 大臣 / 团长 | 高攻击、高魔力 | 术武将 |

贬职后失去指挥权，作为前线单位接受指挥。低攻击、高魔力的角色不具备带兵条件，不因贬职转为前线单位。

---

## 能力轴

角色的能力以两条轴表示，取值为低 / 中 / 高：

| 轴 | 含义 | 与定位的关系 |
| --- | --- | --- |
| 攻击 | 武艺与正面作战能力 | 武将、术武将为高；法师、疗愈师为低 |
| 魔力 | 法术强度与魔法抗性 | 法师、术武将为高；疗愈师为中/高；武将为低 |

魔力的两个用途：

- 施法：决定法术伤害与法术效果强度
- 魔抗：决定承受法术时的抗性

武将魔力低但不为零，仍具备基础魔抗；「低魔力」不等于「无魔抗」。

## 配置项

角色的完整属性字段如下。全部字段均已实现：角色属性在开局页「角色库」或地图设置的角色页签中编辑，同盟、团与职位则在新游戏的「出战角色」中指定。

| 字段 | 取值 / 形式 | 用途 |
| --- | --- | --- |
| 名称 | 字符串 | 显示名与频道署名 |
| 同盟 | 开局配置的同盟槽位 | 归属与配色 |
| 团 | 本团 / 无团（仅我方同盟可分团） | 本团频道上下文归属 |
| 描述 | 文本 | 外貌、经历、立场等角色设定 |
| 职位 | 大臣 / 团长 / 无 | 指挥范围 |
| 定位 | 武将 / 术武将 / 法师 / 疗愈师 | 行为边界 |
| 攻击 | 低 / 中 / 高 | 武艺强度 |
| 魔力 | 低 / 中 / 高 | 施法与魔抗 |
| 性格 | 标签组合，按维度互斥 | Bot 决策权重与 LLM 扮演倾向 |
| 对话提示词 | 文本 | LLM 的说话方式 |
| 作者注释 | 文本 | 给使用者与其他作者的说明 |

同盟名称由开局配置决定，角色只记录槽位；显示名统一为 `【同盟名】团·职务·角色`。

各字段如何进入角色的决策与 LLM 上下文，见《角色行动》第 3、5 章。

扮演类配置参考 AI 酒馆的角色卡结构。因本项目由 LLM 直接在地图上作战，删去了只服务于对话推进、与本项目无关的字段。

## 性格

性格由固定标签组合而成。标签按维度分组，**同一维度内互斥，不同维度可叠加**：

| 维度 | 可选标签 | 作用 |
| --- | --- | --- |
| 胆略 | 勇猛 / 果敢 / 稳健 / 谨慎 / 怯战 | 决定接战意愿，换算为侵略性与谨慎度 |
| 用兵 | 突击 / 拓土 / 固守 | 决定目标偏好，换算为对敌军目标的额外权重 |

例如「勇猛 + 突击」表示敢打且专找敌军，「谨慎 + 固守」表示先守成再图扩张；而「勇猛 + 怯战」属于同一维度，不允许同时选中，从机制上消除互相打架的性格。

每个标签的取值：

| 标签 | 侵略性 | 谨慎度 | 敌军偏好 | 行为倾向 |
| --- | --- | --- | --- | --- |
| 勇猛 | +0.35 | −0.30 | +0.10 | 主动逼近敌军，优先抢占敌占与高价值地块 |
| 果敢 | +0.18 | −0.13 | +0.05 | 有机会就压上，遇强敌会先拉开距离 |
| 稳健 | 0 | 0 | 0 | 占点与避战兼顾，不冒险深入（默认） |
| 谨慎 | −0.16 | +0.17 | −0.06 | 优先稳固后方，绕开强敌只打有把握的仗 |
| 怯战 | −0.32 | +0.33 | −0.12 | 尽量避战，只在安全的空地上扩张 |
| 突击 | +0.05 | −0.03 | +0.15 | 盯着敌军单位打，愿意为咬住敌人绕路 |
| 拓土 | +0.02 | 0 | −0.04 | 优先圈占无主地块，把边界往外推（默认） |
| 固守 | −0.04 | +0.12 | −0.08 | 守成优先，先稳固己方地块再图扩张 |

基线为侵略性 0.5、谨慎度 0.55、敌军偏好 0，选中标签的加成直接相加后取合理区间。同一个组合同时决定三件事，保证执行与发言一致：

- Bot 决策：侵略性提高远处高价值地块的评分，谨慎度提高近处安全地块的评分，敌军偏好提高敌占地块的评分
- LLM 扮演：标签及各标签的行为倾向写入角色提示词，发言与决策不得与该倾向明显冲突
- 界面显示：角色列表以顿号连接显示标签组合；编辑时点「添加性格」打开浮窗，按维度挑选标签，同维度自动替换

标签之外的细微差别写进「描述」或「对话提示词」，不要写进性格。旧版本遗留的自由文本性格在读取时按关键词归并，同一维度只保留最靠前的一个；保存时若同时提交同维度标签，接口直接拒绝。

## 对话提示词

定义 LLM 的发言方式，只影响频道发言，不影响行动指令。

- 可包含说话风格、称呼习惯、口头禅与用词禁忌
- 与性格分工：性格决定倾向，对话提示词决定表达
- 不覆盖职位与定位约束

---

## 作者注释

给使用者与其他作者看的说明。

- 可记录创作意图、灵感来源、平衡备注与待办
- 不影响决策与发言
- 与「描述」的区别：描述是角色设定，作者注释是创作说明

作者注释不进入 LLM 上下文。
