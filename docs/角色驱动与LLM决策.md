# 角色驱动与 LLM 决策

> 本文描述目标设计，与当前 Demo 实现的差异见末节。

---

## 1. 职责划分

LLM 负责扮演角色卡中的角色并作决策，Bot 负责角色在地图上的具体行动。

| 层 | 承担者 | 职责 |
| --- | --- | --- |
| 扮演与决策层 | LLM | 以角色卡中的身份、职位、定位和性格作判断，输出行动指令与频道发言 |
| 执行层 | Bot | 寻路、行军、占领、遭遇战、休整，严格按指令行动，不做战略判断 |
| 降级层 | 模拟 AI | 无可用 LLM 或调用失败时，以本地确定性规则给出指令，保证推演不中断 |

Bot 不解释角色设定，也不自行改变目标；角色的差异化行为来自 LLM，而不是 Bot 的分支逻辑。

---

## 2. 角色扮演

LLM 扮演的依据是角色卡中的字段：

| 字段 | 对决策的约束 |
| --- | --- |
| 名称、描述 | 说话口吻、立场与用词 |
| 职位 | 可指挥的范围：大臣指挥同盟，团长指挥本团 |
| 定位 | 行为边界：武将、术武将可前线带兵；法师、疗愈师不统兵 |
| 攻击、魔力 | 判断自身能承担的战斗强度 |
| 性格 | 侵略性、谨慎度等倾向，同时影响 Bot 行为树的触发概率 |
| 对话提示词 | 发言风格与称呼，不影响行动判断 |

作者注释不进入 LLM 上下文。

扮演规则：

- 发言使用角色自身口吻，同一同盟的不同角色不共享同一套语气
- 决策不得越过定位限制，不统兵的角色不会下达带兵指令
- 职位决定决策的影响面：大臣的决策可要求团长行动，团长的决策只作用于本团团员
- 角色只能感知自己可见的信息，不读取全图状态

---

## 3. 决策触发

LLM 的介入由两类时机触发：随机时间与关键点。决策与发言共用同一套触发规则。

| 类型 | 说明 |
| --- | --- |
| 随机时间 | 相邻两次触发之间没有固定间隔；每次触发后在设定区间内随机决定下一次时机，避免所有角色与同盟在同一回合集体行动 |
| 关键点 | 局势出现需要上层判断的变化时立即触发 |

关键点示例：遭遇战、城池易手、占领地被夺、行军受阻、目标失效、团员全部退场、收到玩家指令。

关键点判定：

- 关键点仅对相关角色触发，不触发全同盟决策
- 同一回合内多个关键点合并为一次决策
- 某角色决策进行中时，新的触发不重复发起，只记录待评估
- 随机时间触发与关键点触发同时到达时，优先执行关键点决策

### 3.1 发言时机

- 世界频道发言与决策同源：随机时间触发时随决策一并产出，关键点触发时按事件性质决定是否发声
- 同盟频道随玩家指令即时回应，不受随机时间限制
- 发言不设固定节拍，避免各同盟在同一回合轮番播报

### 3.2 当前已实现的关键点

| 关键点 | 触发方 | 是否经 LLM | 效果 |
| --- | --- | --- | --- |
| 玩家在同盟频道发言 | 玩家 | 是 | 立即以该发言为指令触发一次决策，指令下发本同盟 Bot，并在同盟频道回执 |
| 玩家在「本团」频道下达军令 | 玩家 | 否 | 本地确定性解析军令后直接下发本团 Bot，不占用 AI 决策通道 |
| 玩家在世界频道发言 | 玩家 | 是 | 仅生成对话回复，不产生行动指令 |

其余关键点（遭遇战、城池易手、占领地被夺、行军受阻、目标失效、团员全部退场）目前尚未接入，Bot 遇到这些情况仍按自身行为树处理，不会请求 LLM 决策。

---

## 4. 决策输入与输出

输入：

- 角色卡：身份、职位、定位、能力与性格
- 可见局势：所属同盟视角下的城池、占领地、己方单位与周边敌方单位
- 近期事件：与本角色相关的遭遇、占领、退场记录
- 频道消息：世界频道与同盟频道的近期发言，含玩家下达的指令

输出：

| 输出 | 去向 |
| --- | --- |
| 行动指令（进攻 / 防守 / 待命 / 撤退 / 自主行动） | 交给 Bot 执行 |
| 频道发言 | 写入世界或同盟频道 |
| 附带目标（地块或城池） | 作为 Bot 寻路与占领的目标 |

无 LLM 可用时，模拟 AI 按相同的输入输出结构给出指令，仅决策质量不同。

---

## 5. 失败与降级

- 调用超时、返回无法解析或接口失败时，当次决策回退模拟 AI
- 同一角色连续失败不阻断推演，只影响该角色当次发言
- 降级不影响指令格式，Bot 无需区分指令来源
- 降级信息只记录在服务端日志，不在界面展示

---

## 6. 与当前 Demo 的差异

| 项目 | 当前 Demo | 目标设计 |
| --- | --- | --- |
| 扮演粒度 | 单一 AI 统一决策，不区分角色 | LLM 按角色卡逐角色扮演 |
| 决策触发 | 随机时间已实现；关键点仅接入玩家指令 | 随机时间 + 完整关键点 |
| 发言时机 | 世界频道随机时间触发；玩家指令即时回应 | 随机时间 + 关键点，与决策同源 |
| 职位 | 未实现，所有角色均为前线单位 | 大臣 / 团长不亲自带兵 |
| 定位 | 未实现 | 武将、术武将带兵；法师、疗愈师为支援单位 |
| 模拟 AI | 已实现，作为无 LLM 时的降级方案 | 保留 |
