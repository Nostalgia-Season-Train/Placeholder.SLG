# 同盟关系

> 本文描述目标设计，暂未实现。当前 Demo 的三势力配色实现见《大地图行军推演.md》第 5 章。

---

## 1. 同盟体系

- 地图上不止三股势力，后续会出现更多同盟
- 同盟关系以玩家所在同盟为参照，分为四类：我方同盟、友方同盟、非友方非敌方、敌方同盟
- 我方同盟内部的「我方核心团」单列，见下文

## 2. 配色规则

| 关系 | 填充 | 边框 | 定义 |
| --- | --- | --- | --- |
| 我方核心团 | 绿色 | 无 | 玩家直接指挥的团 |
| 我方同盟 | 蓝色 | 无 | 与玩家同属一个同盟的其他成员 |
| 友方同盟 | 红色 | 蓝色 | 与我方同盟缔结友好的同盟 |
| 非友方非敌方 | 红色 | 无 | 与我方同盟既非友好也非敌对 |
| 敌方同盟 | 红色 | 红色 | 与我方同盟处于敌对状态的同盟 |

配色沿用现有实现的色值方案（填充与边框解耦渲染），仅术语与关系语义升级。

## 3. 我方核心团

- 玩家直接指挥的团，是玩家在同盟内的基本盘
- 玩家可以绕过 LLM 直接控制核心团的 Bot，指令不经 AI 决策层翻译
- 绝对忠诚：不存在背叛、叛逃与情报泄露
- 「团」与角色卡体系中团长 / 团员的「团」概念对应，具体对应关系待设计

## 4. 我方同盟

- 同盟的其他成员是盟友而非直属力量，对其指令仍经 AI 决策层下达
- 成员中存在内鬼，可能向其他同盟泄露情报
- 成员可能叛逃到其他同盟
- 内鬼的识别与清除、叛逃的触发条件与后果待设计

## 5. 与当前 Demo 的差异

| 项目 | 当前 Demo | 目标设计 |
| --- | --- | --- |
| 势力数量 | 固定三势力（北庭 / 东川 / 西陵） | 多势力多同盟，数量不固定 |
| 我方 | 玩家所选势力整体显示为「我方核心团」 | 仅核心团为我方；同盟其他成员为「我方同盟」 |
| 指挥路径 | 本团频道军令已直达 Bot；同盟频道指令仍经 AI 决策层 | 核心团可绕过 LLM 直接控制 Bot |
| 同盟成员可靠性 | 无此概念 | 存在内鬼泄密与叛逃机制（待设计） |
| 配色色值 | 与本表一致 | 与本表一致 |
