# 同盟关系

> 本文描述目标设计，暂未实现。当前 Demo 的三同盟配色实现见《大地图行军推演.md》第 5 章。

---

## 1. 同盟体系

- 地图上不止三个同盟，后续会持续增加
- 每个同盟都有自己的盟主与同盟频道。玩家所在同盟的盟主是玩家，其余同盟的盟主是 AI 角色，由 LLM 扮演并在本同盟频道内指挥下属，玩家不可旁观
- 同盟关系以玩家所在同盟为参照，分为四类：我方同盟、友方同盟、非友方非敌方、敌方同盟
- 我方同盟内部的「我方核心团」单列，见下文

## 2. 配色规则

| 关系 | 填充 | 边框 | 定义 |
| --- | --- | --- | --- |
| 我方核心团 | 绿色 | 无 | 玩家直接指挥的团 |
| 我方同盟 | 蓝色 | 无 | 与玩家同属一个同盟的其他成员 |
| 友方同盟 | 红色 | 蓝色 | 与我方同盟缔结友好的同盟 |
| 非友方非敌方 | 红色 | 无 | 与我方同盟既非友好也非敌对 |
| 敌方同盟 | 红色 | 红色 | 与我方同盟处于敌对状态的同盟 |

配色沿用现有实现的色值方案（填充与边框解耦渲染），仅术语与关系语义升级。

## 3. 我方核心团

- 玩家直接指挥的团，是玩家在同盟内的基本盘
- 绝对忠诚：核心团角色的提示词写死忠诚约束，因此军令必然照办。约束的写法与执行路径见《角色系统》第 3 章
- 另有一条操作层通路：大地图点选核心团角色直接下达 Bot 级操作，尚未实现，详见《角色系统》第 3.4 节
- 不存在背叛、叛逃与情报泄露
- 核心团不单设盟主，它属于玩家同盟，玩家即盟主
- 「团」与角色属性体系中团长 / 团员的「团」概念对应，具体对应关系待设计

## 4. 我方同盟

- 同盟的其他成员是盟友而非直属力量，对其指令仍经 AI 决策层下达
- 成员中存在内鬼，可能向其他同盟泄露情报
- 成员可能叛逃到其他同盟
- 内鬼的识别与清除、叛逃的触发条件与后果待设计

## 5. 与当前 Demo 的差异

| 项目 | 当前 Demo | 目标设计 |
| --- | --- | --- |
| 同盟数量 | 固定三同盟（北庭 / 东川 / 西陵） | 多同盟，数量不固定 |
| 我方 | 玩家所选同盟整体显示为「我方核心团」 | 仅核心团为我方；同盟其他成员为「我方同盟」 |
| 指挥路径 | 本团频道走同一 LLM 通道、核心团角色提示词带绝对忠诚；同盟频道是与角色的对话，角色自行判断是否执行 | 核心团可另经大地图点选角色直接控制 Bot（复用 LLM 可调用的 Bot 能力） |
| 同盟成员可靠性 | 无此概念 | 存在内鬼泄密与叛逃机制（待设计） |
| 配色色值 | 与本表一致 | 与本表一致 |

## 6. 角色立绘

> 状态：暂未实现。当前地图角色仅有头顶名称标签，无任何立绘形象。

- 角色属性新增「立绘」配置项，与名称、职位、定位等同属角色属性字段
- 占位方案：以纯色填充的矩形牌替代立绘，填充色取该角色所属关系的外交配色，保证低配环境也能区分归属
- 正式方案：按角色属性加载立绘贴图，以面向镜头的精灵牌显示在角色模型上方
- 参考尺寸：占位牌宽 0.8 × 高 1.0 世界单位（约半个地块宽），位于模型上方 1.15 处，名称标签位于其上方
- 缺失立绘时的回退：使用外交配色的纯色填充牌，不显示空白
- 名称标签已实现，立绘牌与名称标签同受外交关系配色控制
