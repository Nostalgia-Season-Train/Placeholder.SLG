# 大地图行军推演

> 本文只描述当前 Demo 已实现的内容，不包含未落地的设计构想。
> 相关代码：`src/game/bot/`、`src/game/map/`、`src/game/agent/`、`src/components/MapTerrain.vue`

---

## 1. 功能概述

三势力 Bot 在程序化生成的六边形地图上自主选择目标、寻路、行军、占领与遭遇战。渲染层使用 Three.js 提供三维地形与行军表现，逻辑层为不依赖框架的纯数据推演，可直接迁移到服务端。

Demo 同时提供：

- Agent 指挥：用中文指令控制指定势力的 Bot
- LLM 接入：兼容 OpenAI chat/completions，未配置或调用失败时回退本地解析
- 通讯频道：世界 / 同盟 / 行军日志
- 设置界面：集中管理推演参数、日志显示与 LLM 配置

---

## 2. 地图

- 尺寸：34 × 34 的尖顶六边形网格，轴向坐标 `(q, r)`，单格半径为 1
- 地形等级 0~5：

| 等级 | 名称 | 通行 | 说明 |
| --- | --- | --- | --- |
| 0 | 荒地 | 可通行 | 干枯平原，几乎没有产出 |
| 1 | 草地 | 可通行 | 基础资源地 |
| 2 | 林地 | 可通行 | 灌木与零散树木 |
| 3 | 丘陵 | 可通行 | 起伏地形 |
| 4 | 山地 | 不可通行 | 岩壁陡峭 |
| 5 | 高山 | 不可通行 | 雪线之上的险峻地形 |

- 山地与高山会自动从寻路节点和占领候选中排除
- 山脉与河流均沿 CatmullRom 脊线生成：山脉脊线核心为高山、外缘为山地，在河滩或水面处断开形成隘口，两端不触及地图边界以保留绕行缺口
- 河流带有流动效果，沿岸生成河滩地块；道路沿地形连接主要区域
- 地块与装饰物统一使用 `InstancedMesh`，单次 draw call 批量渲染
- 三个势力各有一座主城，位于地图中心外围环带，小队从主城相邻的可通行地块出发

## 3. 推演模型

逻辑层按回合推进，每回合所有武将依次行动。核心规则：

- 武将属性：速度 `0.6 ~ 1.0`、战力 `48 ~ 82`，并带有侵略性与谨慎度两项性格参数
- 行动力：每回合增加自身速度，上限 2；移动按地块移动代价扣除
- 目标选择：综合地块等级、距离、当前归属与性格参数评分
- 寻路：A*，绕开不可通行地块
- 占领：在目标地块累计占领进度，达到 `max(2, 地块等级 + 1)` 后完成占领
- 遭遇：敌我单位同格时比较战力随机浮动值，败者撤退并休整 2 回合，胜者占领该地块
- 确定性：随机数使用 `mulberry32` 种子生成器，相同地图与种子可复现完全一致的推演过程
- 输出：每回合生成只读快照，包含武将、城池、占领表、事件与统计

## 4. 行军节奏与表现

推演节拍可选慢 / 中 / 快，对应 1100 / 650 / 350 毫秒每回合。

逻辑层：

- 武将确定新目标或收到新指令时，立即补足迈出第一步所需的行动力，当回合出发，不再空等
- 后续行军仍按行动力与速度规则推进
- 占领需要持续数个回合，战斗失败后需要休整，这两类停顿属于机制行为

渲染层：

- 棋子维护待走地块中心队列，按固定速度匀速步行，约 0.55 秒走一格
- 一帧内可连续走过多个路点，避免帧率波动造成突跳
- 队列超过 4 个路点时丢弃最旧的路点，防止推演速度超过动画时出现长时间追赶
- 高度单独平滑跟随目标地块，保留轻微上下浮动
- 行军路径以连线显示，目标地块显示脉动光环

## 5. 外交关系配色

地图上的占领色块、棋子、行军线、目标环、城池与图例统一按「当前玩家势力与目标势力的外交关系」着色。

| 关系 | 填充色 | 边框 |
| --- | --- | --- |
| 我方 | 绿色 | 无 |
| 同盟友军 | 蓝色 | 无 |
| 非敌军非我方 | 红色 | 无 |
| 敌对同盟 | 红色 | 红色内框 |
| 友好同盟 | 红色 | 蓝色内框 |

关系矩阵（玩家势力切换时生效）：

| 玩家势力 | 赤军 | 青军 | 黄军 |
| --- | --- | --- | --- |
| 赤军 | 我方 | 同盟友军 | 敌对同盟 |
| 青军 | 非敌军非我方 | 我方 | 同盟友军 |
| 黄军 | 同盟友军 | 友好同盟 | 我方 |

实现要点：

- 关系与样式集中定义在 `src/game/bot/diplomacy.ts`，是配色的唯一来源
- 边框使用独立的六边形环几何体与 `InstancedMesh`，逐实例上色，与填充色解耦
- 填充不透明度 0.58，边框不透明度 0.92，边框略高于填充以避免深度冲突
- 玩家势力切换时，占领色块、城池与棋子即时重新着色
- 图例每行显示势力名称与关系文字，色块带同样的内框效果

## 6. Agent、LLM 与通讯

**Agent 指挥**

- 输入中文指令，由 `CommanderAgent` 解析为 Bot 命令：进攻、防守、待命、撤退、自主行动，并指定目标地块
- 已配置 LLM 时调用模型，未配置或调用失败时使用本地解析，保证离线可用
- 支持按固定间隔自动指挥，间隔可在设置中调整

**LLM 配置**

- 兼容 OpenAI chat/completions 接口，需要 baseUrl、model、apiKey
- 配置保存在浏览器 localStorage，不上传
- 同一份配置同时驱动 Agent 指挥与频道聊天

**通讯频道**

- 世界：三方 Agent 共用频道，每 20 回合按势力轮换发送战报与宣言；未配置 LLM 时使用本地文案
- 同盟：仅与当前选中势力的 Agent 对话
- 行军：显示推演事件日志，最新记录显示在最上方

## 7. 设置界面

入口：顶部「设置」按钮；指挥 Agent 面板底部的「LLM 与推演设置」可直接定位到 LLM 页签。

| 页签 | 可配置项 |
| --- | --- |
| 大地图行军 | 推演速度（慢 / 中 / 快）、自动指挥间隔（每 5 / 10 / 20 回合）、地图种子、按种子重新生成 |
| 战况日志 | 显示条数（10 / 14 / 20 / 30）、自动滚动到最新 |
| LLM | baseUrl、model、apiKey、保存与配置状态 |

顶部另保留「暂停 / 继续」与「单步」两个快捷操作。重新生成会清空当前推演进度与行军日志。

## 8. 操作说明

- 拖拽：平移视角
- 滚轮：缩放
- 悬停地块：显示地形等级、描述、坐标与地势
- 悬停城池：显示城池归属

## 10. 已知限制

- 每个势力固定 2 名武将，遭遇战为简化模型
- 主城当前仅作为出生点，尚未实现不可放弃与沦陷易帜规则
- 无存档、无服务端权威计算、无多人联机
- 地图与推演均在浏览器本地生成与运行
