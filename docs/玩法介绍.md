# 玩法介绍

> 面向玩家的上手指南，基于当前 Demo 已实现内容撰写，只介绍现在就能玩到的部分。
> 系统设计细节见《大地图行军推演.md》，角色属性与角色机制见《角色系统/角色属性.md》《角色系统/角色行动.md》。

---

## 1. 这是一款什么游戏

AI 酒馆式的大地图领土争夺游戏。三大同盟在六边形地图上行军、占领、交战，争夺地盘。

与常规 SLG 不同，你（盟主）不逐格操作单位，而是通过频道与角色交流。角色系统如何分层、什么叫「角色行动」，见[概览 · 角色行动的边界](角色系统/概览.md)。

- 每个角色都由 Bot 驱动、由 LLM 扮演决策，角色会按自己的立场回应你，并自行决定是否把话变成行动
- 对话是聊天式的：你一句我一句，不排队、不互斥
- 本团频道的核心团角色绝对忠于盟主，因此军令一定会被执行
- 未配置 LLM 时自动使用本地模拟 AI，游戏完整可玩，接入 LLM 后发言更拟人

分层、决策节奏与频道机制的完整说明见[角色系统](角色系统/角色行动.md)。

## 2. 快速上手

1. 启动：`npm install` → `npm run dev`，浏览器访问 Vite 提示的地址（默认 `http://localhost:5173`）
2. 选择同盟：设置 →「大地图行军」页签 → 当前同盟（北庭 / 东川 / 西陵），决定你看地图的阵营视角与同盟频道归属
3. 配置 LLM（可选）：设置 →「LLM」页签，填入 OpenAI 兼容接口的 baseUrl、model、apiKey；密钥只保存在服务端
4. 在同盟频道与角色对话，例如「向北进攻，拿下河对岸那块地」
5. 观察棋子行军、占领变色，角色把回应发回同盟频道；要确定执行时改到本团频道下令

---

## 3. 指挥方式：三个频道

| 频道 | 用途 | 是否影响 Bot |
| --- | --- | --- |
| 世界 | 与各方公开对话 | 否 |
| 同盟 | 与本方角色对话，角色自行决定是否行动 | 视角色判断 |
| 本团 | 盟主所在核心团，角色绝对忠诚 | 是 |

每个同盟都有自己的盟主与同盟频道；其他同盟的频道不可见。频道的归属与可见性见[概览 · 你与角色的交流](角色系统/概览.md)。

频道机制、作者署名与等待提示的细节见《角色系统》第 3 章。

本团频道军令示例（核心团角色一定会照办）：

- 「全员向北进攻」→ 角色照办，每个 Bot 立即向北推进
- 「进攻 12,8」→ 直接锁定该坐标为进军目标

同盟频道对话示例：

- 「向北进攻」→ 角色挑选北向目标地块并带兵过去
- 「全员防守」→ 就地驻防
- 「待命」→ 原地停留
- 「自由行动」→ Bot 在角色给出的框架内，按地块价值与自身性格自行挑目标

同盟频道是对话而不是命令行：角色可以答应，也可以提出异议、要求补给或直接拒绝，最终行动由角色自己拍板。

## 4. AI 决策节奏

- 角色会自己找时机思考：以设置中的基准间隔为锚点（约 5 / 10 / 20 回合），在 0.5~1.5 倍区间内随机决定下一次，可用「启用自动决策」开关关闭
- 你在同盟或本团频道发言时，角色会立即被唤醒并回应
- LLM 调用失败时当次自动降级为模拟 AI，推演不中断

完整的触发规则、关键点清单与失败降级见[角色系统 · 决策时机](角色系统/角色行动.md)。

## 5. 角色属性：酒馆玩法的核心

地图上的角色由角色属性驱动，属性结构参考 AI 酒馆的角色卡。设置 →「角色」页签点击「添加角色」弹出浮动表单，可创建自定义角色，保存后立即进驻当前世界。

**两个正交维度**

| 维度 | 取值 | 作用 |
| --- | --- | --- |
| 定位 | 武将 / 术武将 / 法师 / 疗愈师 | 能力倾向与前线职责 |
| 职位 | 大臣 / 团长 / 无 | 指挥权范围；只有「无」亲自带兵上图 |

**属性字段**

- 攻击 / 魔力：低 / 中 / 高三档，换算为地图战力
- 性格：标签文本（如「勇猛、谨慎」），映射为 Bot 的侵略性与谨慎度
- 描述、对话提示词：塑造 LLM 的扮演与发言风格
- 作者注释：给创作者看的说明

各字段如何进入角色的决策与上下文，见《角色系统》第 3、5 章。

首次启动自动种入 9 名内置角色：每同盟 1 名大臣（坐镇不上图）加 2 名武将（从主城旁出发）。

## 6. 推演与战斗规则

- 地图：34 × 34 尖顶六边形网格，地形等级 0~5；山地与高山不可通行，寻路自动绕开
- 行军：A* 寻路；行动力每回合按速度累积（上限 2），移动按地块代价扣除；棋子匀速步行约 0.55 秒一格
- 占领：角色驻留目标地块，累计 `max(2, 地块等级 + 1)` 回合完成占领
- 遭遇战：敌我同格时比较战力随机浮动值，败者撤退并休整 2 回合，胜者占领该地块
- 外交配色：我方绿、同盟友军蓝、非敌军非我方红、敌对同盟红底红框、友好同盟红底蓝框；切换当前同盟后全图即时重新着色

---

## 7. 推演控制

- 标题栏快捷操作：暂停 / 继续
- 设置 →「大地图行军」：当前同盟、启用自动决策、决策基准间隔、推演速度（慢 1100 / 中 650 / 快 350 毫秒每回合）、地图种子、按种子重新生成
- 按种子重新生成会清空当前推演进度与频道消息，地图与局势从头开始

---

## 8. 存档

- 手动存档：设置 →「存档」页签，命名保存、读取、删除
- 自动续档：每 5 回合、重开世界、读取存档、服务退出前自动写入；服务启动时自动恢复到上次进度
- 存档为完整世界快照（回合、占领、事件、角色状态、随机序列、频道消息），恢复后从存档回合继续，不依赖重放

---

## 9. 地图操作

- 拖拽平移视角，滚轮缩放
- 悬停地块：显示地形等级、描述、坐标与地势
- 悬停城池：显示归属同盟
- 标题栏「帮助」：地形等级、场景要素、同盟外交配色、行军规则与频道指令示例

## 10. 与目标设计的差距

当前 Demo 与完整愿景之间已知的差距，游玩时可能感知到：

| 项目 | 当前状态 |
| --- | --- |
| 主角与角色的关系 | 单一 AI 统一决策，尚未按角色属性逐角色扮演 |
| 决策触发 | 随机时间已实现；Bot 侧关键点尚未接入 |
| 指挥链与定位职能 | 大臣、团长的指挥链未接入；法师、疗愈师暂无支援职能 |
| 大地图直接指挥 | 尚未实现，目前只能经频道下达指令 |
| 主城规则 | 主城仅作出生点，无沦陷易帜规则 |

角色系统侧的完整差距见《角色系统》第 11 节。
