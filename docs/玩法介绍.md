# 玩法介绍

> 面向玩家的上手指南，基于当前 Demo 已实现内容撰写，只介绍现在就能玩到的部分。
> 系统设计细节见《大地图行军推演.md》《角色卡.md》《角色驱动与LLM决策.md》。

---

## 1. 这是一款什么游戏

AI 酒馆式的大地图领土争夺游戏。三大势力在六边形地图上行军、占领、交战，争夺地盘。

与常规 SLG 不同，你（盟主）不直接操作任何单位。你在频道里向由 LLM 扮演的角色下达指令，AI 决策层把你的意图翻译成具体命令，交给 Bot（武将行动层）执行，战况回执发回频道。

```
盟主（你） → LLM（扮演角色卡角色，决策层） → Bot（武将，执行层）
```

- Bot 只负责执行：寻路、行军、占领、遭遇战、休整
- AI 负责决策：把「向北进攻」这类方向性指令解析为「进攻哪块地、谁去」的具体命令
- 未配置 LLM 时自动使用本地模拟 AI，游戏完整可玩，接入 LLM 后决策与发言更拟人

## 2. 快速上手

1. 启动：`npm install` → `npm run dev`，浏览器访问 Vite 提示的地址（默认 `http://localhost:5173`）
2. 选择势力：设置 →「大地图行军」页签 → 当前势力（北庭 / 东川 / 西陵），决定你看地图的阵营视角与同盟频道归属
3. 配置 LLM（可选）：设置 →「LLM」页签，填入 OpenAI 兼容接口的 baseUrl、model、apiKey；密钥只保存在服务端
4. 在同盟频道发言下达指令，例如「向北进攻」
5. 观察棋子行军、占领变色，AI 把决策回执发回同盟频道，行军日志同步滚动

---

## 3. 指挥方式：三个频道

| 频道 | 用途 | 是否影响 Bot |
| --- | --- | --- |
| 同盟 | 本方指令入口：发言即下令，AI 解析后执行并回执 | 是 |
| 世界 | 与三方 AI 公开对话；每 20 回合各势力轮换发布战报宣言 | 否 |
| 行军 | 只读推演事件流水，最新记录在最上方 | — |

同盟频道指令示例：

- 「向北进攻」→ AI 挑选北向目标地块，命令武将行军占领
- 「全员防守」→ 就地驻防
- 「待命」→ 原地停留
- 「自由行动」→ Bot 在 AI 给定的框架内，按地块价值与自身性格自行挑目标

---

## 4. AI 决策节奏

- 定时决策：按设置中的间隔（每 5 / 10 / 20 回合）统一评估局势，可用「启用自动决策」开关关闭
- LLM 调用失败或返回无法解析时，当次自动降级为模拟 AI，推演不中断，降级只记录在服务端日志
- 当前版本的同盟频道指令为单轮决策：一次发言触发一次决策，暂不保留跨回合的长期作战计划

---

## 5. 角色卡：酒馆玩法的核心

地图上的武将由角色卡驱动，卡面结构参考 AI 酒馆的角色卡。设置 →「角色」页签可创建自定义角色卡，保存后立即进驻当前世界。

**两个正交维度**

| 维度 | 取值 | 作用 |
| --- | --- | --- |
| 定位 | 武将 / 术武将 / 法师 / 疗愈师 | 能力倾向与前线职责 |
| 职位 | 大臣 / 团长 / 无 | 指挥权范围；只有「无」亲自带兵上图 |

**卡面字段**

- 攻击 / 魔力：低 / 中 / 高三档，换算为地图战力
- 性格：标签文本（如「勇猛、谨慎」），映射为 Bot 的侵略性与谨慎度
- 描述、对话提示词：塑造 LLM 的扮演与发言风格
- 作者注释：给创作者看的说明，不进入 LLM 上下文

首次启动自动种入 9 张内置卡：每势力 1 名大臣（坐镇不上图）加 2 名武将（从主城旁出发）。

## 6. 推演与战斗规则

- 地图：34 × 34 尖顶六边形网格，地形等级 0~5；山地与高山不可通行，寻路自动绕开
- 行军：A* 寻路；行动力每回合按速度累积（上限 2），移动按地块代价扣除；棋子匀速步行约 0.55 秒一格
- 占领：武将驻留目标地块，累计 `max(2, 地块等级 + 1)` 回合完成占领
- 遭遇战：敌我同格时比较战力随机浮动值，败者撤退并休整 2 回合，胜者占领该地块
- 外交配色：我方绿、同盟友军蓝、非敌军非我方红、敌对同盟红底红框、友好同盟红底蓝框；切换当前势力后全图即时重新着色

---

## 7. 推演控制

- 标题栏快捷操作：暂停 / 继续、单步
- 设置 →「大地图行军」：当前势力、启用自动决策、决策间隔、推演速度（慢 1100 / 中 650 / 快 350 毫秒每回合）、地图种子、按种子重新生成
- 设置 →「战况日志」：显示条数、自动滚动开关
- 按种子重新生成会清空当前推演进度与行军日志，地图与局势从头开始

---

## 8. 存档

- 手动存档：设置 →「存档」页签，命名保存、读取、删除
- 自动续档：每 5 回合、重开世界、读取存档、服务退出前自动写入；服务启动时自动恢复到上次进度
- 存档为完整世界快照（回合、占领、事件、武将状态、随机序列、频道消息），恢复后从存档回合继续，不依赖重放

---

## 9. 地图操作

- 拖拽平移视角，滚轮缩放
- 悬停地块：显示地形等级、描述、坐标与地势
- 悬停城池：显示归属势力
- 标题栏「帮助」：地形等级、场景要素、势力外交配色、行军规则与频道指令示例

## 10. 与目标设计的差距

当前 Demo 与完整愿景之间已知的差距，游玩时可能感知到：

| 项目 | 当前状态 |
| --- | --- |
| 扮演粒度 | 单一 AI 统一决策，尚未按角色卡逐角色扮演 |
| 决策触发 | 仅定时触发，遭遇战、城池易手等关键点触发尚未接入 |
| 指挥链 | 大臣、团长仅存在于角色卡数据，指挥链未接入 AI 决策 |
| 定位职能 | 法师、疗愈师作为普通 Bot 单位参战，支援/恢复/控制职能未实现 |
| 性格联动 | 性格仅映射目标选择权重，逃跑介入等行为树联动未实现 |
| 主城规则 | 主城仅作出生点，无沦陷易帜规则 |
